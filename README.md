# Personal Bill Payment Tracker

## About

A command-line Python application to manage personal bills,
record payments, track pending bills, and monitor upcoming
due dates.

## Features

- Add, view, update, and delete bills
- Record bill payments
- Track paid and unpaid bills
- View upcoming bills
- Identify overdue bills
- Calculate total expenses
- View payment history
- Store data using JSON files

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Modules
- Date and Time

  - payments.json

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

   python main.py

No external libraries are required.

## Data Storage

Bill records and payment history are stored
locally in JSON files inside the data folder.
